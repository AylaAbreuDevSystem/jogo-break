# Jogo Break 🎮

Um jogo tipo Brick Breaker desenvolvido em Dart/Flutter.

## 📋 Descrição

Brick Breaker é um jogo clássico onde o jogador controla uma paleta para rebater uma bola e quebrar blocos na tela. O objetivo é quebrar todos os blocos sem deixar a bola cair.

## 🚀 Características

- Gameplay clássico de Brick Breaker
- Controles intuitivos
- Efeitos visuais
- Sistema de pontuação

## 📥 Instalação

### Pré-requisitos
- Flutter SDK instalado
- Dart SDK (incluído no Flutter)

### Clonar o repositório
```bash
git clone https://github.com/AylaAbreuDevSystem/jogo-break.git
cd jogo-break
```

### Instalar dependências
```bash
flutter pub get
```

## ▶️ Como Executar

```bash
flutter run
```

## 🛠️ Tecnologias

- **Dart** - Linguagem de programação
- **Flutter** - Framework para desenvolvimento mobile
